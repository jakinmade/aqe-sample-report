# AQE sample report

A sample AI deployment qualification produced by AQE (aqediagnostic.com).
Excel Invests and Jason Butler are fictional. No real organisation or person is assessed.

- [Qualification certificate (PDF)](AQE-sample-certificate.pdf): the verdict and the reasons for it
- [Evidence book (PDF)](AQE-sample-evidence-book.pdf): every finding, each required action, and all 24 answers with scores
- `index.html`: a one-page summary of the same report

AQE uses fixed, version-controlled rules with no AI model in the decision, so the same inputs always produce the same verdict.
